# FAQ

## Does this force me to build a multi-agent system?

No. Its first gate can conclude that no system, a direct model task, or a deterministic workflow is the correct answer.

## Do I need Codex, Claude, and Antigravity together?

No. One installed host receives the complete method. Teams and cross-host collaboration are optional.

## Does installing the Skill grant new permissions?

No. It can use only the tools and authority already available in that host and authorized for the task.

## Is it a framework?

It is a governed architecture and verification method with templates, schemas, tests, and portable host carriers. It can help choose a framework, but it does not require one.

## Can it design a single autonomous agent?

Yes. Multi-agent topology is an outcome of necessity analysis, not a requirement.

## Can it design a team?

Yes, after the necessity gate records why multiple processes or hosts add measurable value, or when the human explicitly requests a bounded team.

## Why are architecture mode, autonomy, and risk separate?

Because topology does not determine authority. A single agent can be high risk; a team can be read-only and low autonomy.

## Is the release “secure” or “unhackable”?

No project can honestly promise that. Releases are tested against declared threat families and bounded scanners. Read the exact scope and limitations in the evidence.

## Why are there both Skills and plugins?

The Skill folder is the portable runtime payload. Plugins are host-specific distribution carriers that make installation and discovery easier without changing the doctrine.

## Why use a tagged URL?

A tag gives a release a stable version name, but a tag can be moved by a repository maintainer. Record the commit SHA resolved from the tag and verify the release checksum; do not treat the tag name alone as proof of bytes.

## Can I install with `npx skills`?

Yes, as a secondary community convenience. Select exactly one supported `--agent`, review its detected target, and use copy mode. Prefer the host's official installation route and do not assume the CLI supports Antigravity.

## Why is Cursor marked format-compatible rather than live-qualified?

Compatibility with the documented Agent Skills format is different from a fresh runtime behavior gate. The claim is upgraded only after that gate is recorded for a release.

## Can I publish a modified version?

Yes under Apache-2.0, subject to its notice and attribution terms. Rename forks if their doctrine or release identity diverges, so users do not mistake them for the canonical project.

## How do I report an issue?

Use the issue template for bugs, documentation, or host compatibility. Report sensitive vulnerabilities privately through GitHub Security Advisories.
