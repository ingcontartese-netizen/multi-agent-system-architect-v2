## Baselines And Comparisons

Define no-system, deterministic workflow, single-agent, or previous-release baselines. Compare verified success, cost, latency, intervention, complexity, and governance.

## Negative And Recovery Cases

Cover malformed output, missing authority, stale catalog, timeout, cancellation, crash/resume, duplicate trigger, approval expiry, provider failure, malicious retrieval, memory correction/delete, and budget breach.

## Artifact And Visual QA

Define content-retention, schema, link, searchable text, outline, print/export, responsive, anonymous-mode, media license, and actual-output checks.

## Release Gate

Predeclare shadow/canary population, success and rollback thresholds, observation window, approver, evidence level, and widening criteria. Do not move thresholds after results are known.

## Rollback And Exit

Define trigger, procedure, owner, state/data handling, compatibility, readback, and residual risk.

## Completion Rule

PASS requires processed/expected denominators, no unresolved critical check, independent verification, and explicit next gate.

## Contract Bundle And Version Gates

Validate every artifact through its declared V1 or V2 schema and dispatcher. Record version, owner, risk, reference resolution, negative fixtures, and compatibility evidence before release.

## Completion Evidence

The run needs an owner. Record task, output, artifact, run, and outcome completion separately. Each applicable level needs criteria identifiers, evidence locators, and an independently checked status.
